# Photo to Merch Studio

Create a coherent postcard-and-sticker collection from real photographs. Preserve the photograph's identity; use design, extraction, framing, texture, and typography to transform it into merchandise rather than automatically redrawing it.

## Load references

- Read `references/artistic-directions.md` when transforming a photograph into collectible art or an art-postcard front. Use only its three confirmed directions unless the user explicitly requests another experiment.
- Read `references/visual-system.md` before choosing color, background, texture, tape, ribbon, vellum, acetate, transparent film, or another banded material.
- Read `references/type-layouts.md` when the postcard includes text or placeholders.
- Read `references/postcard-back-systems-research.md` when selecting or refining a premium postcard back, especially when the user requests multiple back layouts or criticizes a photo-to-paper transition.
- Read `references/crop-and-frame-library.md` before selecting a photographic edge transition or creating architectural stickers, film strips, or portrait detail crops.
- Read `references/production.md` before producing final or print-ready files.
- Read `references/qa.md` before delivery.

## Scope

Support three selectable outputs without requiring all three:

1. Postcard only.
2. Sticker set only.
3. Postcard and sticker set together.

For the current version, exclude vinyl-record and album-packaging concepts.

## Workflow

### 1. Inspect the request and inputs

Determine whether the task is:

- travel, landscape, architecture, food, animal, or object photography;
- personal portrait photography;
- celebrity, performer, or music fan material.

Check resolution, crop, sharpness, visible faces, subject separation, text legibility, and likely print suitability. Record the intended use and whether the user requested postcard, stickers, or both. If the user explicitly confirms noncommercial use, record that once and do not repeatedly interrupt concept development with the same rights note.

Do not fabricate ownership. For celebrity, commissioned, or commercial work, briefly flag that photograph, likeness, trademark, and lyric rights may need permission. A noncommercial label does not prove permission, but it is enough to continue exploratory samples unless another restriction blocks the work.

### 2. Establish a direction before rendering

Do not impose a default medium such as watercolor or illustration. Preserve photographic realism unless the user explicitly asks for drawing or the photograph cannot support a clean photographic treatment.

When the user asks for artistic transformation, collectible artwork, or an art-postcard system, select exactly one confirmed direction from `references/artistic-directions.md`:

1. Photo + Oil Fusion;
2. Artist Travel Archive;
3. Museum Art Collection.

The source photograph is reference input, never a fourth artistic direction. For an explicit direction comparison, generate exactly three transformed outputs—one D1, one D2, and one D3—and show the untouched source separately as `REFERENCE ONLY`. Before choosing a crop or output ratio, run the subject, protected-region, aspect-ratio, and composition selection checks in `references/artistic-directions.md`.

Treat the transformed artwork as a locked master before adding postcard structure. Do not ask image generation to invent the artwork and the product layout in one uncontrolled step when identity, landmark geometry, or repeatability matters. Validate the art master first, then derive the front and matching back from it.

When the requested product is a postcard, a front alone is incomplete. For every approved front, create a matching back with the same finished dimensions and orientation, usable writing space, an address treatment, and a visible stamp position. Omit the back only when the user explicitly asks for front-only artwork or a transformation-only study. Before delivery, count front/back pairs; the counts must match.

Choose:

- one back-side hero ground: a source-derived chromatic ground, film-black, or film-white. When the work must attract as a product, prefer an identifiable source color over a pale neutral default;
- warm or cool temperature from the photograph's emotion;
- 3–6 accent colors from a supplied reference image, or from the source photograph when no reference exists;
- one texture treatment from `references/visual-system.md`;
- one layout direction from `references/type-layouts.md` when text is present;
- postcard orientation from the source composition;
- white-border, borderless, or mixed sticker treatment.

If the user has not specified these choices, make a reasoned selection and state it briefly. Favor a bold photographic editorial identity: film black/white, restrained color accents, freeform cropping, modest analog texture, and generous negative space.

### 3. Select memory elements

Choose sticker subjects according to information density rather than a fixed count. Prefer:

1. primary subject;
2. place-defining or identity-defining detail;
3. story-bearing small object;
4. supporting environmental detail;
5. no more than a few non-narrative decorations.

Examples include a landmark, vehicle, sign, chair, animal, food, accessory, stage prop, clothing detail, cloud silhouette, plant, or architectural fragment.

Allow a small number of stars, lines, tape pieces, frames, stamps, or abstract marks. Do not invent narrative objects or events.

Tape and banded materials are optional spatial elements, never a default signature. Use one piece or a purposeful 2–4-piece ensemble only when it is grounded in the current input and performs named tasks such as attaching, connecting, passing behind type, masking, crossing an edge, extending movement, creating a barrier, or expressing missing memory. In an ensemble, every piece needs its own role and the group needs one shared compositional purpose; more pieces are not permission for decoration. Select and audit material, length, direction, layering, protected regions, and ensemble roles with `references/visual-system.md`; omit the material when no concrete task exists. Never choose angle first: mark the real connection points or source axis, then derive each strip angle from the placement reserve in `references/visual-system.md`. Reject a strip whose angle does not visibly belong to the subject, layer boundary, type baseline, or movement it serves.

Run the independent-meaning test before keeping any fragment: name what the fragment communicates without seeing the source. Keep it only when the answer is specific, such as complete landmark, skilled action, distinctive jewelry, meaningful expression, material texture, or identifiable scene perspective. Delete fragments whose only explanation is “it looks decorative.”

Use as many elements as the photograph genuinely supports. Avoid padding a sparse image with meaningless stickers.

For album, celebrity, or packaged-product references, inventory the source before inventing containers. Separate every meaningful existing component that can stand alone: person, record, disc, booklet, mirror, badge, fabric item, prop, typography fragment, or recognizable object. Prefer clean cutouts of these components over repeatedly placing the entire source image inside different frames.

#### Landscape and architecture exception

Do not force a landscape into a literal object-extraction workflow. When a landscape has few detachable objects, design a freer photographic sticker vocabulary from the view itself:

- window, porthole, doorway, viewfinder, or film-frame views;
- a complete architectural silhouette or roofline;
- vertical scene slices and tall contact-print fragments;
- water, cloud, canopy, bark, stone, path, or reflection fragments;
- negative-space shapes, map-like routes, color swatches, and restrained graphic marks derived from the photograph;
- one or two small atmospheric decorations that support the scene without inventing a story.

A rectangular photograph fragment must read as an intentional frame, not an accidental crop. Never cut a continuous mountain ridge, roofline, horizon, or landmark through an arbitrary horizontal edge. Prefer a complete silhouette, a vertical crop, or a clearly enclosed window/film frame.

Treat a named landmark as an indivisible primary subject. Before rendering, identify its full outer silhouette and protect it in every landmark sticker. A film strip, stamp window, or porthole that claims to show the landmark must contain the complete recognizable building unless it is explicitly labeled as an architectural detail study.

### 4. Preserve truth and identity

- Preserve real people as photographs by default.
- Never place a heavy black frame tightly beside or around an isolated head by default; it can read as a memorial portrait. Use film-white, a source-derived hairline, visible environmental context, or no frame, and preserve the complete head.
- For celebrity material, keep the real face and identity; edit the background, edge, crop, color, and decoration rather than redrawing the face.
- If the user names a specific song, album, tour, or era, research and lock that period before designing. Use a photograph from the requested period and derive the palette, stage cues, typography, and symbols from that period rather than from the celebrity's generic public image.
- When the request is “cut the person out,” treat it as background extraction only. Keep the person's face, body, clothing, pose, and source pixels unchanged.
- If an image-generation service blocks public-figure transformation, or if generation risks changing the person's identity, switch to a deterministic layout path: place the authorized photograph unchanged inside masks, frames, crops, and typographic compositions. Never attempt to bypass the restriction.
- Generate multiple useful portrait formats when appropriate: full figure, half body, headshot, and portrait-plus-symbol composition.
- Use portrait detail crops only when the crop has independent narrative value. Preserve the full head in ordinary portrait and jewelry crops. A neck, hand, hat, sleeve, or accessory alone is not meaningful by default.
- Allow a headless crop only for a deliberate fashion/product study in which the face is intentionally irrelevant and the photographed object is complete. Never create an accidental decapitation or amputated-looking crop.
- Use hands only when they perform a legible action or reveal craft, relationship, or character. Delete an isolated hand that merely occupies space.
- Prioritize the accuracy of faces, landmarks, clothing, signature objects, and readable signs.
- Simplify minor background details when helpful.
- Keep readable source text accurate. If uncertain, remove it, convert it into a clearly non-linguistic graphic shape, or ask the user. Never output accidental pseudo-text.
- Use only exact lyrics, names, dates, and quotations supplied or confirmed by the user. Never invent lyrics.

### 5. Build stickers

Create a mixed set when composition permits:

- some stickers with irregular handmade cut-paper white borders;
- some borderless photographic cutouts;
- optional framed or rectangular photo-fragment stickers;
- only a few purely decorative stickers.

Let the visual direction override the mixed treatment when consistency requires all bordered or all borderless.

Border is a design decision, not a default manufacturing outline. A photographic cutout may be borderless; a handmade white edge may appear only where it improves separation, tactility, or rhythm. Do not put the same border around every sticker automatically.

Use this order for every sticker: **identify a meaningful subject → extract its true silhouette → clean the mask → decide whether separation requires an edge → choose an edge that follows the subject or its native image geometry**. Never choose an arch, circle, stamp, tag, or film frame first and then force an unrelated photograph into it. Do not disguise repeated copies of one product image as variety by changing only their containers.

Select white edges, film frames, and photo-to-paper transitions from `references/crop-and-frame-library.md`. Keep them controlled rather than uniformly thin: a thicker paper edge, torn edge, film rebate, or luggage-tag frame is valid when it suits the photograph. “Simple” means avoiding unrelated ornament, not removing useful structure. Use the subject silhouette, structural lines, native material, or image geometry—not a generic oval or feathered rectangle—to create interest.

For preview mockups, a subtle paper shadow is allowed. Remove shadows from individual transparent files and print layouts.

### 6. Build the postcard

Choose the front composition from the photograph rather than forcing one template. Options include a full-bleed hero image, hero image with sticker margin, contact-sheet collage, split crop, framed editorial image, or layered photo fragments.

Design the back with an address area and a stamp position, but do not default to a rigid vertical divider. Choose a flexible back system from `references/type-layouts.md`: open field, offset address island, floating stamp window, edge index, correspondence grid, image echo, or another composition that belongs to the front. When the back needs visual evidence from the source, abstract a meaningful element with `references/crop-and-frame-library.md` instead of repeating two thumbnails of the same complete photograph. Add lyric, note, caption, place, or date only when the user supplies or requests it. When text has not been supplied but a reusable template is needed, use visible placeholders such as `PLACE` and `TIME`; never invent personal details.

Before styling the back, select one identifiable **hero color** from a meaningful source region—such as sea, sky, floor, lamp light, façade stone, or clothing—rather than averaging the entire photograph into muddy beige. Use that color as the dominant field when it improves product appeal, and select postal lines, type, and stamp marks for clear contrast. The hue must remain recognizable at thumbnail size while the writing and address functions stay usable. Follow the chromatic-ground and product-appeal gates in `references/visual-system.md`.

Preserve approved back-side signatures across revisions. Do not erase a subject silhouette, image-echo stamp window, full-art field, material band, open address arrangement, `PLACE`/`TIME` hierarchy, or a tape attachment with a demonstrated spatial task merely to make the system more uniform. Do not propagate that tape to unrelated backs. A vertical card must be designed and presented as a vertical card; never place it inside a horizontal white presentation mat.

Choose orientation before designing either side:

- use horizontal when the protected subject and eye flow depend on a horizon, lateral architecture, environmental portrait context, long object, or panoramic depth;
- use vertical when the protected subject depends on standing figure scale, tower/column height, tall interior recession, falling movement, or a vertically organized object;
- keep the native orientation when both are plausible;
- never rotate or re-crop the back independently: it must match its front exactly.

The source-photo/transformed-result comparison is a social preview format, not the default finished postcard.

### 7. Produce the deliverables

When postcard and stickers are requested, create:

- postcard front;
- postcard back;
- sticker sheet;
- individual transparent stickers, including white-border and pure-cutout variants when feasible;
- print-ready exports;
- social presentation mockup.

Separate presentation files from production files. Apply shadows, table surfaces, external mockup tape, and dimensional staging effects only to presentation mockups. When tape or a banded material is an intentional artwork element selected through `references/visual-system.md`, retain its flat artwork layer in the relevant production export but remove mockup-only shadows, perspective, and fake lighting.

### 8. Validate and package

When the user requests all results, inventory every existing output folder before packaging. Include the specifically referenced earlier groups as an easy-to-find curated subset and include a complete assets snapshot so older Sydney, forest, portrait, border, film-frame, tape, or other approved tests cannot be silently omitted.

Run the checks in `references/qa.md`. Keep drafts, revisions, and final files distinct. Package outputs using the directory structure in `references/production.md`.

## Failure handling

- If a face changes or becomes unrecognizable, return to the original photographic face and reduce generative edits.
- If public-figure generation is blocked, create the concept with non-generative cropping, masking, layout, and typography while keeping the source pixels unchanged.
- If a cutout fails around hair, fur, glass, or translucent material, use a framed photographic sticker or manually corrected mask instead of delivering a damaged edge.
- If the source is too small for print, label the result preview-only and request a higher-resolution source.
- If the photograph does not contain enough meaningful elements, make a smaller sticker set.
- If text cannot be verified, omit or replace it with an explicitly decorative non-text shape.
- If a requested texture obscures the photograph, lower its strength or remove it.

## Style boundary

The signature must come from a consistent art direction, not a single forced filter:

- real photograph remains recognizable;
- a source-derived chromatic, film-black, or film-white ground chosen for the subject and product role;
- source/reference-derived accent color;
- asymmetrical, free but controlled editorial arrangement;
- mixed handmade and clean cut edges;
- restrained analog surface character;
- exact, sparse typography;
- postcard and stickers unmistakably belong to one collection.

Photography is the default signature. For border tests, lock the source photograph, crop, color, exposure, and subject pixels; change only the outer edge or frame. Transform the photographic medium only when the user explicitly asks for a non-photographic experiment.
